Vice Coast 3D is an open-world crime, street racing, and stunt action game featuring a neon-lit coastal city, realistic car physics, drifting, high-speed nitro boosts, an escalating wanted police system with helicopters and roadblocks, story missions, weapons, and a 100% offline Three.js client.

## Features
- **Neon-Lit Coastal City**: Explore the sprawling coastal metropolis with beaches, skyscrapers, highways, and hidden ramps.
- **Realistic Car Physics & Drifting**: Experience responsive vehicle handling, power slides, drifting mechanics, and high-velocity nitro boosts.
- **Escalating Wanted Police System**: Dynamic pursuit AI featuring cruiser barricades, road spikes, tactical swat interventions, and police attack helicopters.
- **Story Missions & Objectives**: Crime contracts, time-trial street races, and stunt jumps across the city.
- **Weapons & Combat**: On-foot third-person combat, arsenal weapon switching, and responsive crosshair targeting.
- **Offline Three.js Engine**: Fully self-contained local web client with zero external CDN dependencies.

## How to Play

Run the built-in development server:
```bash
node serve.ts
```

Then open your browser and navigate to:
```
http://localhost:8080
```

### Controls
- **W / A / S / D** or **Arrow Keys**: Steer / Accelerate / Brake / Move
- **Space**: Handbrake / Jump
- **Shift**: Nitro Boost / Sprint
- **F / Enter**: Enter / Exit Vehicle
- **Left Click**: Fire Weapon
- **Right Click / Aim**: Lock-on Crosshair
- **1 - 4**: Switch Weapon
- **C**: Switch Camera View
- **Esc / P**: Pause Game
